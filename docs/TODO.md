## 2. 그 외 (낮은 우선순위)

- **명시적 로그아웃 ("퇴장하기")**: 현재는 disconnected 상태로 자리 유지. 사용자가 명시적으로 맵에서 제거하고 싶을 때
- **이모티콘 / 액션**: 춤추기, 박수, 손 흔들기 등 단순 액션 (`emote` 이벤트)
- **사용자 채팅 채널/토픽**: 회의실 진입 시 해당 회의실 인원끼리만 채팅 (현재는 전체+근접만)
- **WebRTC 음성/영상 통화**: 본 MVP에서 명시적으로 제외했으나 추후 회의실 존 진입 시 활성화 가능
- **모바일 반응형 / 터치 컨트롤**: 현재는 데스크탑 우선, 키보드 입력
- **신고/관리자 처리 시스템**: 현재 미구현 (40명 지인 그룹). 더 큰 그룹으로 확대 시 부활
- **퀴즈 풀**: 사용자별 1개가 아닌 여러 개 → 매칭 시 랜덤 선택
- **퀴즈 카테고리/태그**: 어려움·재미·잡학 등 분류 후 사용자 선호도 매칭
- **이벤트 모드**: 특정 시간에 모두 같은 위치에 텔레포트, 일제히 시작 등
