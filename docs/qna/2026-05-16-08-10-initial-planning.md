- 공개 서비스 아님 → IP 캐릭터/1784 실사 모두 사용 가능
- 프로젝트 디렉토리: `NarinTown/`, 문서는 `NarinTown/docs/`
- 온보딩 마무리: "2nd Anniversary" 케이크 + 아바타 촛불 끄기 (5초 컷씬)
- 환영 문구: "3년차로 Level-Up을 축하합니다"
- 신고 기능 제외 (지인 그룹)
- 재접속 시 **마지막 위치** 그대로 (시작점 X)

- 잠든 사용자도 퀴즈 응답 가능 (입력 시 자동 깨어남)

- 랭킹은 **Top 5**, **1~3위는 메달(🥇🥈🥉) 표기**

- 파일명에 **시각(HH-MM)까지** 포함
