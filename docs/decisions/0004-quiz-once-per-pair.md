# ADR 0004 — OX 퀴즈: 상대별 1회 + 비대칭 페어링

- **상태**: Accepted
- **작성일**: 2026-05-16

## 배경

OX 퀴즈는 본 프로젝트의 핵심 게임 메커니즘. 사용자가 만날 때마다 무제한 도전 가능하면 점수 인플레이션 + 친한 사람끼리 점수 몰아주기 가능. 따라서 만남의 가치를 보존할 제약 필요.

또한 잠든/끊긴 사용자에게 강제 응답 요구는 부당. 그러나 페어링 유발자(자발적으로 접근한 쪽)는 책임지고 응답해야 게임성 보장.

## 결정

### 1. 상대별 1회 도전 정책
- 같은 페어(A→B)는 최대 1번만 도전 가능
- 재도전 불가, 결과는 영구 기록
- A→B와 B→A는 서로 다른 도전 (각각 1회씩)

**구현**: `Attempt` 테이블에 `@@unique([challengerId, targetId])` 제약 → DB 레벨에서 강제

### 2. 페어 매칭 트리거: 근접 시 자동 팝업
- 두 사용자가 일정 거리(N 타일) 이내면 서버가 페어 락 획득 시도
- 락 획득 시 양쪽에 `quiz:prompt` 송신
- 매칭 후 5초 쿨다운으로 재충돌 방지

### 3. 15초 응답 시간 제한

### 4. 비대칭 처리 (페어링 유발자 vs 대상)

| 역할 | 상태 | 미응답 시 |
|---|---|---|
| 유발자 (이동해서 접근한 쪽) | active | **기권 처리**: `Attempt(guess=null, forfeited=true)`, 점수 0, 콤보 리셋, 기회 소진 |
| 대상 | active | **기권 처리**: 유발자와 동일 |
| 대상 | sleeping / disconnected | **기회 유지**: `Attempt` 미생성, 다음 만남에서 재도전 가능 |

**판정 로직**: 페어링 직전 tick에서 위치 변화 큰 쪽이 유발자. 둘 다 움직였다면 거리 변화 더 큰 쪽(접근 속도).

## 대안과 트레이드오프

### "전체 1회" 정책
- 한 번 실패하면 끝, 더 긴박
- ❌ 첫 사람에게 운 나쁘게 만나면 너무 빨리 끝남, 상호작용 줄어듦

### "퀴즈별 1회" 정책 (같은 퀴즈에 한해서만 1회)
- 사용자가 여러 퀴즈 보유 가능 → 매칭 시 랜덤 선택
- ✅ 더 유연
- ❌ MVP 범위 키움. 본 결정은 단순화 선택

### 대칭 처리 (잠든 사용자도 기권)
- ✅ 구현 단순
- ❌ 잠든/끊긴 사용자가 부당하게 기회 소모 → 불공정

## 결과

### 장점
- 만남 한 번 한 번이 가치 있음 → 적극적 이동 유인
- 잠든/끊긴 사용자에 공정성 보장
- DB 유니크 제약으로 데이터 무결성 자동 보장

### 부담
- 유발자 판정 로직 구현 필요 (위치 변화 추적)
- 비대칭 처리 분기 → 테스트 케이스 다양화 필요
